# Финальный проект Flask: Блог с карточками

Учебное веб-приложение с авторизацией, базой данных SQLite и стилизацией.

## 🚀 Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `python main.py`
3. Откройте: `http://127.0.0.1:5000`

## 🗄️ База данных
- Таблица `users`: id, username, password
- Таблица `card`: id, title, subtitle, text

## 🔐 Маршруты
- `/` — стартовая страница (home)
- `/login`, `/register` — авторизация
- `/index` — все карточки (только для авторизованных)
- `/create` — создание карточки
- `/card/<id>` — просмотр карточки
